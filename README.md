# eco-smat-campus-all-india-authority-portal
Yeh ek comprehensive "National Civic Action, Population &amp; Waste Analytics Network" web application hai. Is portal ka main objective aam janta (citizens) aur government authorities (jaise Municipal Corporations, PWD Engineers) ko ek direct platform par connect karna hai. Iske zariye log real-time mein kachra (waste), kharab sadke, aur air pollution
